# Mockups de la PoC

Generados con la herramienta integrada imagegen. Propuestas visuales estáticas, sin conexión a la API. Nombre provisional: Contrasta. Usuario simulado: Ale Jiménez. Fuentes y datos ficticios.

- desktop.png: vista de escritorio con historial y navegación lateral.

La identidad gráfica y tipografía son exploratorias; deben unificarse al implementar. El ejemplo muestra el estado ámbar para explorar su presentación; en el producto, una duplicación contradicha por cifras comparables se clasificaría como refutada (rojo).
